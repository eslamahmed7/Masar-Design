# مشاريع العملاء

يُنشأ هذا المجلد تلقائياً بواسطة أداة `tools/prepare.mjs` — لا تنشئ مجلدات هنا يدوياً.

## بنية مجلد مشروع واحد

```
<اسم-المشروع>/
├── index.html      ← يعيد التوجيه إلى المشغل المشترك (يُنشأ تلقائياً)
├── project.json    ← بيانات المشروع كما صدّرها Masar Editor
└── assets/         ← البانورامات والصور وملفات PDF
```

الرابط النهائي: `https://masar-viewer.pages.dev/<اسم-المشروع>/`

## ملاحظة مهمة

المشغل المشترك (صفحة الهبوط + الجولة) موجود في الملفات:
`viewer.html` · `viewer.css` · `viewer.js` · `vendor/pannellum/`

فلا يُنسخ داخل كل مشروع — كل مجلد مشروع يحتوي بياناته فقط، وهذا يبقي الموقع خفيفاً وسهل التحديث.

# لقطات الشاشة — فحص الجودة (QA)

لقطات شاشة كاملة (Full-page) لجميع صفحات الموقع على أربعة مقاسات شاشة،
ملتقطة بواسطة Playwright + Chrome headless خلال فحص الجودة.

## المقاسات

| المجلد | المقاس | النوع |
|--------|--------|-------|
| `mobile` | 390×844 (×2) | iPhone 12/13/14 — موبايل |
| `mobile375` | 375×812 (×2) | iPhone X/XS — موبايل صغير |
| `tablet` | 768×1024 | iPad Air |
| `desktop` | 1440×900 | شاشة كمبيوتر |

## الصفحات (9 لقطات لكل مقاس)

| الملف | الصفحة |
|-------|--------|
| `home.png` | الصفحة الرئيسية |
| `projects.png` | معرض المشاريع |
| `project-details.png` | صفحة تفاصيل مشروع |
| `services.png` | الخدمات |
| `about.png` | عن مسار |
| `contact.png` | تواصل معنا |
| `start.png` | ابدأ مشروعك |

| `404.png` | صفحة الخطأ 404 |

## ملاحظات

- جميع الصفحات تُرجع HTTP 200 (عدا صفحة 404 المتعمّدة).
- **لا يوجد تجاوز أفقي (horizontal overflow)** في أي مقاس.
- **لا توجد صور مكسورة** في أي صفحة (تم إصلاح صورة الـHero المكسورة ببديل تلقائي).
- اللقطات تُحدَّث عند كل تشغيل لفحص الـQA؛ أمر إعادة الالتقاط:
  `node crawl.js` (داخل مجلد أدوات الـQA في `Temp/opencode/masar-qa`).
